# Scenario Lab fixtures

Reference payloads for the three live-demo paths in the React Scenario Lab.
They are intentionally small and map to the `hiring_demo_v1` adapter.

- `case_a_green.json` - clean, high-confidence decision path.
- `case_b_yellow.json` - borderline review path (model-dependent but tuned for YELLOW).
- `case_c_red_policy_block.json` - deterministic policy hard block via `emotion_score`.
